Bump the data.js cache-buster so the re-based ledger actually reaches the browser

The Sep 9 by-line re-base (8136d77) rewrote data.js and electrical-control.html but
left index.html requesting `data.js?v=20260909c`. Any browser that had already
loaded the dashboard kept serving the cached old data.js, which carries no
`alcance`, `proyecto` or `lineaPlan` — and renderElectricalByLine() returns early
when those are absent, so the electrical section rendered unchanged or empty even
though main was correct.

- index.html: data.js ?v=20260909c -> 20260909d
- index.html: electrical-control.html ?v=20260820a -> 20260909d (2 links; the study
  changed in the same re-base)

Standing rule: if data.js changes, the ?v= on its script tag changes in the same
commit.
